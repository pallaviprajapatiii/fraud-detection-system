# AI-Powered Fraud Detection System
Java Swing + JDBC + MySQL project (Topic 70)

# Features
- Admin and Customer login
- Customers send money (commit/rollback used)
- A background thread checks every transaction against fraud rules
- Admin can see alerts and mark them as reviewed

## How to run
1. Run schema.sql in MySQL
2. Put your MySQL password in DBConnection.java
3. Run Main.java
